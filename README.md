# IPTV 直播源自动检测与分类

> 基于 GitHub Actions 的 IPTV 直播源自动检测、源龄分析、多维度分类工具。  
> 支持并发检测、防盗链识别、真实更新时间获取、持久化缓存。

---

## ✨ 核心特性

| 特性 | 说明 |
|------|------|
| 🔄 自动触发 | `live.txt` / `check_iptv.py` / `check.yml` 任一变动即自动运行 |
| ⚡ 高效检测 | 多线程并发（默认10线程），HEAD→GET 降级，超时20s |
| 🛡️ 防盗链识别 | 403 源区分：GitHub限流(保留) / 网页防盗链(保留) / 私人CDN(标记失效) |
| 📅 智能源龄 | GitHub/Gitee API → JsDelivr → Last-Modified → URL日期 → git log → 未知 |
| 🏷️ Date头降级 | HTTP `Date` 仅标记"今日活跃"，**不污染更新分档**，避免误判 |
| 💾 持久缓存 | `source_age_cache.json` 记录检测结果，逐次积累，未知比例递减 |
| 📊 多维度输出 | 按可用性、响应时间、源龄四档、僵尸源自动分类 |

---

## 📂 输出文件

| 文件 | 说明 |
|------|------|
| `live_ok.txt` | ✅ 可用源（按源龄四档+字母序排列） |
| `live_ok.m3u` | 📺 可用源播放列表（按响应时间排序） |
| `live_fail.txt` | ❌ 真失效源（连通失败） |
| `live_week.txt` | 🆕 一周内真实更新且可用 |
| `live_month.txt` | 📅 一个月内更新 |
| `live_3month.txt` | 📆 三个月内更新 |
| `live_old.txt` | 🧓 超三个月全部源 |
| `live_stale.txt` | 🧟 超90天且不通的僵尸源 |
| `live_report.csv` | 📋 9列详细报告（生成时间/更新日期/状态码/响应ms/状态/类型/源龄/分档/备注/网址） |
| `source_age_cache.json` | 🗄️ 源龄检测缓存（自动读写，加速后续运行） |

### 源龄分档规则

| 分档 | 条件 | 说明 |
|------|------|------|
| 🆕 一周内 | ≤7天 且可用 | 近期活跃源 |
| 📅 一个月内 | ≤30天 | 较新源 |
| 📆 三个月内 | ≤90天 | 正常维护源 |
| 🧓 超三个月 | >90天 | 老源（仍存活） |
| ❓ 未知 | 无法获取更新时间 | 含仅返回Date头的403防盗链源 |
